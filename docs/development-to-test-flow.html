发布与测试的先后关系

推送只包含确认时的变更。后续生成的测试文件留在本地，不会自动补推，也不自动创建 PR、合并主分支或部署。

自动执行的前置条件

测试文件优先执行；没有测试文件且提供本机 HTTP 预览地址才走浏览器。被测应用需提前启动，平台不会自动启动应用。

重试与中断

用例规划与执行共用最多三轮循环，浏览器脚本格式最多修正一次。服务重启中断自测时转为 REVIEW，保留记录供继续自测。
